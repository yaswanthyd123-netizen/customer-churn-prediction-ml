# Customer Churn ML Task Submission

Files:
- `ML_problem_framing_memo.md`: decision framing, target, unit, baseline, error costs, human safeguards.
- `responsible_data_card.md` and `.html`: dataset card (HTML is a clean standalone version).
- `customer_churn_baseline.ipynb`: runnable baseline notebook.
- `risk_register.md`: risk controls and rollback.
- `customer-churn-training.csv`: source dataset.

Important limitation: the CSV contains only 12 rows. This is an educational demonstration, not a validated model. The uploaded HTML file appeared to be RabTech Academy website HTML rather than a data-card template, so the card was created as a separate standalone file instead of modifying it.
